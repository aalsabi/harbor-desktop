# تقرير التوافق والفجوات — 2026-09-23

هذا إصدار تجريبي قابل للتشغيل، وليس تنفيذ جميع وظائف macOS أو سطح مكتب إنتاجياً مكتمل الاختبار. لا يمكن استنتاج توافق العتاد من نجاح البناء داخل حاوية.

| المجال | الموجود | الفجوة أو حد التحقق |
|---|---|---|

## أدلة الاختبار

- أربع مجموعات Qt: التفضيلات والأوامر، الإشعارات، فهرس التطبيقات، DBusMenu مع خدمة اختبار فعلية.
- خمس حالات Python: عدم وجود KWin، عزل إعداداته، إنهاء الأبناء بعد خروجه، مخرجات التشخيص، رجوع العرض بمحاكي.
- اختبار واجهة يرسم صورة فعلية ويتحقق من نجاح العملية وحجم الصورة؛ هذا لا يعوض اختبار النقر لكل عنصر.
- اختبار KWin افتراضي ينشئ نافذتي إعدادات ويتحقق من تعدادهما والتفعيل والإغلاق وفتح خمسة ألواح وإرسال إشعار.
- لا اختبارات فعلية للبطارية أو Wi-Fi أو Bluetooth أو suspend/resume أو crash-safe lock أو تبديل مستخدم أو GPU أو screen sharing.

الأدلة الخام تضم إصدارات البناء والأوامر ونتائجها. التحذيرات المتعلقة بخدمات النظام الغائبة داخل الحاوية لا تعتبر اختبارات ناجحة لهذه الخدمات. لا يوجد قياس رسومي على جهاز حقيقي في هذا التسليم.

## الاختلاف عن macOS Golden Gate

المرجع هو Golden Gate27 الرسمي وقت البحث؛ الشبه في تنظيم شريط علوي وdock ومركز تحكم وواجهة إعدادات موحدة. لا Apple menu أو SF Symbols أو خط San Francisco أو خلفيات Apple أو رموزها التجارية. لا إعادة تنفيذ Finder أو Spotlight الكامل أو iCloud أو AirDrop أو Continuity أو تطبيقات Apple. بعض الوظائف تعتمد أدوات Linux خارجية وتبدو مختلفة. اسم Harbor وأصوله مستقلان؛ لا ادعاء اعتماد من Apple.

## نتيجة التحقق النهائي

| الاختبار | التصنيف | الدليل |
|---|---|---|
| بناء Debian13 Qt6.8 | نجح | evidence/trixie-validation.txt |
| مجموعات Qt الأربع | نجح | السجل نفسه |
| حالات Python الخمس | نجح | السجل نفسه |
| تثبيت الحزمة وإزالتها | نجح | PACKAGE_INSTALL_RUNTIME_REMOVE_PASS |
| رسم معاينة الواجهة | نجح | اختبار UI والصورة المولدة |
| تعداد وتفعيل وإغلاق نوافذ KWin | نجح، compositor افتراضي | kwinWindowEnumeration/activate/close |
| تشغيل الجلسة المثبتة وإعداداتها | نجح، compositor افتراضي | installedSessionStartup/settingsWindowManaged |
| رجوع إعدادات العرض | محاكاة فقط | tests/test_display.py |
| تشغيل تطبيقات X11 عبر XWayland | لم ينفذ | الحاوية لا تحتوي socket X11 النظامي؛ لا تعتمد نجاح جلسة Wayland كدليل X11 |
| القفل والعتاد والبوابات والوصول | لم ينفذ | تحتاج جهاز اختبار |

ظهرت تحذيرات KWin عن ثيم المؤشر الافتراضي وغياب /tmp/.X11-unix في الحاوية، وتحذيرات Qt عند إنهاء الجلسة. لم تمنع اختبارات Wayland المذكورة، لكنها لا تمنح اعتماداً لتجربة X11 أو القفل. على نظام Debian كامل يجب تهيئة دليل X11 عبر حزمة x11-common وخدمات النظام قبل استخدام XWayland.
