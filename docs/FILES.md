# Harbor Files — 0.3.0

مدير ملفات مستقل مستوحى من تنظيم Finder، بأصول Harbor الأصلية. يعمل على ملفات Linux المحلية ويُفتح من زر Files في dock، أو بالأمر harbor-files، أو من قائمة التطبيقات. لم يتغير مدير الملفات الافتراضي للنظام تلقائياً.

## الاستخدام

- انقر مرتين لفتح مجلد أو ملف بالتطبيق الافتراضي. Ctrl+نقرة لتحديد عدة عناصر.
- غيّر العرض بين Icons وList وColumns؛ عرض الأعمدة يوضح المجلد الأب والمجلد الحالي ومحتويات المجلد المحدد.
- الشريط الجانبي يعرض المجلدات الشائعة والأقراص المركبة. اكتب مساراً في الأعلى؛ Ctrl+L يحدد خانة المسار.
- من قائمة ••• اختر New tab، أو Ctrl+T لتبويب جديد؛ Ctrl+W يغلق التبويب الحالي إذا كان هناك غيره. Alt+يسار/يمين للسجل وAlt+أعلى للمجلد الأب.
- البحث يرشح أسماء عناصر المجلد المفتوح فقط، وليس محتويات الملفات أو القرص كله.
- Ctrl+H لإظهار الملفات المخفية، Space لإظهار/إخفاء المعاينة. المعاينة تدعم صوراً محدودة الحجم والنصوص حتى64KiB؛ لا تشغيل تلقائي للملفات.
- Copy/Cut ثم Paste للنسخ/النقل. حافظة العمليات داخل نافذة Harbor Files الحالية.
- قائمة الزر الأيمن تضم فتحاً ونسخاً وقصاً وإعادة تسمية ونقلاً لسلة النظام. F2 لإعادة تسمية عنصر واحد.
- السحب والإفلات يستقبل روابط ملفات محلية؛ النسخ افتراضياً وShift للنقل. اختبار السحب عبر تطبيقات خارجية لم يُنفذ.
- New folder من قائمة ••• ينشئ مجلداً؛ لا تقبل إعادة التسمية مساراً أو اسماً يحتوي /.

## حماية الملفات وحدود العمليات

لا تُستبدل الوجهة الموجودة تلقائياً. يظهر الخطأ وتبقى النسخة السابقة. الروابط الرمزية تُنسخ كروابط؛ لا تُجتاز أثناء نسخ المجلدات. النقل لسلة المهملات يتم عبر GIO، مع تأكيد في الواجهة، ولا توجد عملية حذف دائم في التطبيق. استرجاع المهملات يتم بأداة النظام؛ واجهة استرجاع داخلية غير موجودة بعد.

العمليات تعمل في عملية منفصلة عن رسم الواجهة؛ يظهر مؤشر انشغال ونتيجة نصية. لا يوجد Undo عام أو دمج مجلدات أو شريط تقدم تفصيلي. عند فشل عملية متعددة العناصر قد تكون العناصر السابقة قد اكتملت؛ لا توجد معاملة تراجع جماعي. لا تغلق التطبيق أثناء النسخ؛ قد تبقى نسخة جزئية عند انقطاع العملية، ويجب فحصها قبل حذف الأصل.

## الفجوات عن Finder

لا iCloud أو AirDrop أو Tags أو Spotlight indexing، ولا Gallery/Quick Look لملفات PDF والفيديو. لا دعم شبكات SMB/SFTP داخل هذا الإصدار ولا تركيب/إخراج أقراص، ولا ترجمة عربية كاملة لواجهة الملفات. قراءة قوائم المجلدات محلية ومتزامنة حالياً؛ المجلدات الضخمة أو الأقراص البطيئة تحتاج تحسيناً واختباراً إضافياً. لا ادعاء تطابق Finder100%.

## التحقق

اختبارات Python تستخدم ملفات مؤقتة لا بيانات المستخدم: نسخ شجرة وروابط رمزية، عدم استبدال ملف موجود عند النقل، إعادة تسمية ومنع مسار خارج الاسم، ومنع نسخ المجلد داخل نفسه. اختبارات Qt تتحقق من سجل التنقل والتبويبات والترشيح والمخفي ومعاينة النص. اختبار Qt Quick ينقر عنصراً ويغير طرق العرض ويفتح مجلداً بالنقر المزدوج. الرسم برمجي offscreen؛ السحب والإفلات عبر التطبيقات والأقراص الفعلية لم يُعتمدا بعد.

الإصدار0.3 يستخدم شريط أدوات موحداً وزخرفة نافذة خاصة. النقاط يساراً تغلق وتصغر وتكبّر النافذة، ويمكن الوصول إليها بلوحة المفاتيح. اسحب الشريط لتحريك النافذة، والزاوية السفلى اليمنى لتغيير الحجم. الزر ◧ يظهر المعاينة، و••• يحتوي عمليات الملفات التي كانت ظاهرة كأزرار مستقلة.

## Panel menus (0.3.2)

With a Harbor Files window active in the Harbor Wayland session, the panel displays File, Edit, View, Go and Window. These menus act on that window and respect its selection and busy state. Rename, new-folder and trash actions use the existing dialogs. Edit operations target the focused text editor when editing text, otherwise the file selection. View options show their selected states.

Each Files process exports its own DBusMenu endpoint, associated with its Wayland surface through KWin's appmenu protocol. Other applications still need their own DBusMenu support; this update does not invent menus for unsupported apps. The local toolbar actions remain available outside Harbor.
