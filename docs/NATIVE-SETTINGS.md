# Native System Settings — 0.9.0

Harbor uses its own Qt Quick settings pages on KWin Wayland, without Plasma Shell or embedded KDE settings windows. English interface language is independent of Saudi regional formats. All new pages support English/Arabic and light/dark preferences; no hover tooltips are used.

## Runtime services and safety

Privileged actions use the appropriate system service and its authentication policy. Battery thresholds use a fixed, validated helper invoked through polkit. Network secrets are held in memory/D-Bus, not command arguments or logs; account passwords are hashed in memory before AccountsService submission. Destructive actions have native confirmation dialogs. Display changes have an independent rollback process even if the settings window closes.

Harbor's session owns the power/accessibility helpers and starts selected startup applications once. Running a settings window alone does not start an idle policy or screen reader. Helpers report missing dependencies and service failures rather than presenting a successful setting that was not applied.

## Dependencies

Install the Debian package with recommended dependencies enabled for the full feature set. Network import needs `python3-gi`, `gir1.2-nm-1.0` and the OpenVPN NetworkManager plugin; audio streams need `pulseaudio-utils`; display brightness uses `ddcutil`; idle policy uses `swayidle`; screen reading uses `orca`; updates use `packagekit`; printer administration uses `cups-pk-helper`. Native isolation requires `bubblewrap` with permitted user namespaces and a Wayland session. Printer discovery uses CUPS backends and Avahi for DNS-SD; repository driver installation uses PackageKit. Flatpak remains optional.

## Validation boundaries

Automated tests use temporary configuration, fake commands and private D-Bus services. Runtime rendering checks load the actual pages; Debian package validation installs/runs/removes Harbor only inside a disposable container. These are not evidence of physical printer output, Bluetooth radio pairing, real external-monitor brightness, firmware charge control, speech quality, real package upgrades or hardware gesture recognition. Validate those on the target device before production rollout. Apple cloud services and exact macOS parity are not implemented.
