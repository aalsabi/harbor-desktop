# Harbor Desktop — مواصفة التصميم

التاريخ: 2026-09-23. الحالة: اعتمد المستخدم الاتجاه المعماري KWin + shell مخصص دون Plasma Shell؛ لا يوجد تنفيذ أو حزمة تشغيل بعد.

## الغرض وحدود النجاح

جلسة سطح مكتب مستقلة لـDebian تقلل صعوبة انتقال مستخدمي macOS، مع shell وشريط قوائم وdock ومركز تحكم وتطبيق إعدادات متكاملين. المرجع البصري macOS Golden Gate 27، والاسم والأصول والكود للمشروع مستقلة. لا تعني عبارة «كاملة» إعادة تنفيذ تطبيقات Apple أو خدماتها؛ تعني جلسة Linux قابلة للاستخدام، تشمل المكونات المطلوبة وإدارة دورة الجلسة والتثبيت والإزالة والتوثيق. كل وظيفة غير مكتملة تسجل كفجوة، ولا يستعاض عنها بزر يوحي بأنها تعمل.

## التحقق من المرجع

تؤكد صفحة Apple الحالية الاسم macOS 27 Golden Gate. تصف تحسينات الزجاج والتباين، اتساق الأدوات، امتداد الأشرطة الجانبية وأشكال النوافذ ومؤشرات شريط القوائم، ومنزلقاً للتحكم في درجة الزجاج. هذه خصائص موثقة، وليست قياسات هندسية دقيقة لمقاسات الواجهة. لم تجر مقارنة بكسلية مع جهاز Mac فعلي. لا نفترض أن صور Tahoe تمثل Golden Gate تماماً.

المصادر التي تمت مراجعتها في التاريخ أعلاه:

- https://www.apple.com/os/macos/ — هوية الإصدار وخصائص التصميم الحالية.
- https://support.apple.com/en-us/148830 — تأكيد اسم Golden Gate 27 من دعم Apple.
- https://support.apple.com/en-my/guide/mac-help/mchlp1446/mac — توزيع قوائم التطبيقات وحالة النظام والبحث ومركز التحكم في الشريط العلوي.
- https://www.debian.org/releases/ — Debian 13 / trixie أساس الإصدار المستقر.
- https://packages.debian.org/trixie-backports/hyprland — النسخة المعروضة 0.55.2+ds-1~bpo13+1؛ يلزم اختبار حل الاعتماديات فعلياً قبل اعتماد الحزمة.
- https://packages.debian.org/trixie/labwc — بديل stacking ضمن stable، النسخة المعروضة 0.8.3-1؛ محدود التأثيرات عمداً.
- https://packages.debian.org/trixie/liblayershellqtinterface-dev — ربط Qt بطبقات Wayland.
- https://wayland.app/protocols/wlr-layer-shell-unstable-v1 — الحواف والطبقات والمساحة المحجوزة.
- https://networkmanager.dev/docs/api/latest/spec.html — واجهات إعداد الشبكة.

بعض روابط دليل Control Center وAppearance المباشرة لم تستجب؛ لا تنسب الوثيقة إليها تفاصيل غير متحققة. يجب استكمال تدقيقها وصور المرجع أثناء تنفيذ المقارنة البصرية.

## القرار المعتمد

Qt6/QML + KWin على Wayland + مكتبات KDE Frameworks المناسبة، مع shell وتطبيق إعدادات من تطوير المشروع. لا تشغيل لـplasmashell ولا استخدام panels أو widgets أو session startup الخاصة بـPlasma. Hyprland وlabwc خارج نطاق التنفيذ. اسم Plasma في مستودع مكتبة KDE لا يعني استخدام Plasma Shell؛ يجب تدقيق اعتماديات الحزم الفعلية وعدم سحب plasma-desktop كحزمة تجميعية.

الهدف Debian 13 amd64، Qt 6.8 وKWin 6.3 كأساس توافق. دعم arm64 يحتاج بناء واختبار مستقلين. Debian يعرض kwin-wayland 6.3.6 ضمن trixie: https://packages.debian.org/trixie/kwin-wayland . لا نبني compositor جديداً.

KWin لا يوفر بمفرده الإشعارات أو إدارة الجلسة أو مركز التحكم. هذه مسؤوليات Harbor وخدمات مستقلة مفتوحة المصدر. البروتوكولات الخاصة بـKDE وإذن وصول العميل لها تُختبر في النسخة المستهدفة؛ لا نفترض أن واجهات wlroots أو Hyprland تعمل على KWin.

## المكونات وعقودها

- `harbor-shell`: Qt6 Quick، سطح خلفية، شريط لكل شاشة، dock، مشغل تطبيقات، مركز تحكم. LayerShellQt لربط النوافذ بالحواف وحجز المساحة. فصل النوافذ المنبثقة عن المساحات المحجوزة؛ إغلاق بـEscape وإدارة تركيز لوحة المفاتيح.
- `harbor-settings`: تطبيق مستقل يستخدم مكتبة الواجهات وخدمات النظام المشتركة؛ البحث في الأقسام، تنقل بلوحة المفاتيح، عربي/إنجليزي واتجاه RTL/LTR.
- `harbor-core`: نماذج الحالة ومخزن الإعدادات ومحولات D-Bus والعمليات الخارجية غير المتزامنة. الحالات: متاح، غير متاح، جارٍ التطبيق، فشل. لا يظهر نجاح قبل قراءة الحالة الفعلية مجدداً.
- `CompositorAdapter`: قائمة الشاشات والنوافذ، التركيز والإغلاق ومساحات العمل وضبط العرض. KWin/KDE Wayland protocols للنوافذ ومساحات العمل، وKScreen لضبط الشاشات؛ لا اعتماد على Hyprland IPC. يجب التحقق من السماح بالبروتوكولات المقيدة للعميل دون انتحال هوية Plasma. فحص قدرات وقت التشغيل وتعطيل الوظائف غير المدعومة بوضوح.
- `session`: تسجيل الدخول من display manager، agent لـPolkit، portals، keyring، notifications، lock/idle، XWayland ودورة إنهاء العمليات. جلسة جديدة لا تغير جلسة المستخدم الحالية.
- `themes/assets`: رموز SVG وخلفية أصلية، design tokens وQt palette وGTK stylesheet اختياري. لا San Francisco ولا SF Symbols ولا شعارات أو أصوات أو خلفيات Apple.

تستخدم إشعارات النظام خدمة مفتوحة المصدر قائمة عبر freedesktop Notifications؛ لا نسجل خادمين متنافسين. تُكتشف خدمات portals وPolkit المتاحة ويُتحقق من تشغيلها في جلسة الاختبار.

## السلوك المطلوب

### Shell والقوائم وdock

الشريط: قائمة Harbor، اسم التطبيق النشط، قوائم التطبيق حين يصدّر DBusMenu، بحث، شبكة/صوت/بطارية، مركز تحكم وساعة. التطبيقات التي لا تصدر قوائم تبقي قوائمها داخل نافذتها؛ لا قوائم File/Edit صورية. دعم tray وفق StatusNotifierItem ضمن نطاق التنفيذ، مع توثيق التطبيقات القديمة غير المتوافقة.

Dock: تطبيقات مثبتة وعمليات جارية ومؤشر نشاط، تشغيل/تركيز/اختيار نافذة، تثبيت وإزالة وإخفاء اختياري. قراءة Desktop Entry وفق XDG، احترام Hidden/NoDisplay، وعدم تفسير Exec عبر shell. دعم الملفات/الروابط باستخدام أدوات XDG المخصصة. البحث في التطبيقات المثبتة هو النطاق الأول؛ بحث محتويات الملفات ليس مكافئ Spotlight كاملاً.

### مركز التحكم والإعدادات

| القسم | التكامل المطلوب | التعامل مع الصلاحيات/الغياب |
|---|---|---|
| الشبكة | NetworkManager: حالة، Wi-Fi، اتصال وقطع وإدارة الشبكات المحفوظة | الطلبات عبر السياسات القائمة؛ لا كلمات مرور في السجلات |
| الصوت | PipeWire/WirePlumber، ضبط الجهاز الافتراضي والصوت والكتم | عمليات غير متزامنة بمهلة؛ غياب الخدمة موضح |
| Bluetooth | BlueZ: تشغيل، مسح، اقتران واتصال | agent مفتوح قائم عند الحاجة، مع توضيح الإحالة |
| العرض | compositor: الشاشة والدقة والقياس والترتيب | معاينة مع رجوع تلقائي خلال 15 ثانية إذا لم يعتمد المستخدم |
| السطوع والطاقة | backlight المدعوم، UPower، power-profiles-daemon عند توفره | لا اعتبار غياب backlight عطلاً؛ لا ضبط ملفات sysfs عشوائياً |
| المظهر | لون، فاتح/داكن، عتامة، تقليل الحركة، حجم dock والخلفية | حفظ خاص بالمستخدم وتحديث المكونات الحية |
| المستخدمون | AccountsService وPolkit | لا daemon بصلاحية root من تصميم المشروع |
| التحديثات | PackageKit عند توفره أو فتح مدير حزم Debian موثق | عرض المعاملة والتقدم والأخطاء؛ لا ترقية صامتة |
| الإدخال | إعداد لوحة المفاتيح والتخطيطات والمؤشر في compositor | حفظ ورجوع، وعدم افتراض توافق إعدادات GNOME |
| الجلسة | logind للقفل/التعليق/الخروج والطاقة | احترام inhibitors وفشل الخدمة؛ قفل فعلي عبر خدمة متوافقة مع KWin؛ يمنع استبداله بنافذة تغطي الشاشة |

العمليات الحساسة تظل خاضعة لتفويض Debian. الإحالة لأداة خارجية مقبولة فقط إذا سميت بوضوح في الواجهة ودليل الفجوات؛ لا توصف كتنفيذ أصلي داخلي مكتمل.

## اللغة البصرية الأصلية

اسم عمل: Harbor، وليس منتج Apple. لوحة ألوان بحرية مع لمسة كهرمانية، رموز هندسية أصلية وخط Noto المتاح بترخيص حر. المقاسات التالية قرارات تصميم خاصة وليست أرقاماً من Apple: شريط 30 وحدة منطقية، dock بأيقونات 48 ووحدات تباعد 8، تدوير بطاقات 16، حركة قصيرة 140–220ms قابلة للإلغاء. الوضع المعتم يحافظ على المقروئية عند غياب blur. لا يدعي blur الخطي محاكاة الانكسار البصري الحقيقي لـLiquid Glass.

أزرار النوافذ في تطبيقات Harbor تكون يسار العنوان مع أسماء وصول واضحة. زخارف التطبيقات الأخرى تعتمد على client/server decoration؛ GTK4/libadwaita والإلكترون قد لا تتبع الثيم بالكامل. لا نفرض ترقيعات على البرامج الخارجية.

## التثبيت والرجوع

حزمة user-facing تسجل جلسة Harbor مستقلة. لا تستبدل ملفات المستخدم مباشرة، ولا تفعل مستودعاً أو تجعل الجلسة افتراضية سراً. ملفات افتراضية ضمن /usr/share، والاختيارات ضمن XDG_CONFIG_HOME/harbor. الاستيراد ينسخ إعدادات المستخدم احتياطياً عند طلبه. إزالة الحزمة تزيل ملفاتها فقط وتبقي بيانات المستخدم، ويشرح الدليل طريقة حذفها اختيارياً. فحص إصدار KWin قبل توليد config، ومطابقة قاعدة الإعدادات للنسخة المختبرة، لا الاعتماد على wiki أحدث دون اختبار.

## خطة التحقق ومعايير القبول

1. بناء نظيف: Qt وQML والاعتماديات والحزمة؛ فحص المحتويات والتراخيص وعدم تضمين أسرار أو ملفات خارج المشروع.
2. اختبارات منطقية: تحليل .desktop، حماية وسيطات التشغيل، حفظ الإعدادات واستعادتها، اختفاء خدمات D-Bus، مهلة العمليات، وإبلاغ فشل التغييرات.
3. جلسة Wayland متداخلة: طبقات صحيحة، مساحة محجوزة، focus، تشغيل تطبيقين والتبديل بينهما، مركز التحكم، الإعدادات، إعادة تشغيل shell دون سقوط compositor.
4. Debian 13 نظيفة: تثبيت الحزمة، الدخول والخروج، إزالة نظيفة، توافق Qt6 وGTK3 وGTK4 وElectron وXWayland، العربية وتكبير 100/150/200% وشاشتان.
5. تكامل فعلي: تغير الصوت والشبكة والشاشة، رجوع العرض التلقائي، رفض Polkit، قفل/تعليق، إشعارات ومشاركة شاشة عبر portal. لا يكفي mock لإعلان نجاح هذه الحالات.
6. الأداء: حفظ مواصفات CPU/GPU/RAM ونسخ المكتبات؛ قياس RSS وCPU للـshell وللجلسة منفصلين بعد دقيقة استقرار، زمن ظهور اللوحات عبر 30 عينة، frame times أثناء الحركة. أهداف أولية لا نتائج: استجابة اللوحات p95 أقل من 150ms وCPU خمول للـshell أقل من 2% من نواة على جهاز مرجعي يحدد في التقرير. لا تعميم لقياسات headless على GPU فعلي.
7. كل صف في التقرير يصنف: نجح، فشل، لم ينفذ، محاكاة فقط. لا أرقام أداء تقديرية تعرض كقياسات.

## الفجوات المعروفة مسبقاً

- لا تشغيل لتطبيقات macOS، Siri AI أو Apple Intelligence أو iCloud أو AirDrop الأصلي.
- لا تطابق 100% في الخطوط والأيقونات والانكسار والحركات وأزرار كل نافذة.
- القوائم العالمية مشروطة بدعم التطبيق؛ تصميم موحد لكل GTK4/Electron غير مضمون.
- اختصارات Super شبيهة بـCommand على مستوى الجلسة، لكن اختصارات تطبيقات Linux لا تعاد كتابتها كلها.
- غياب Plasma Shell يتطلب بناء إدارة الجلسة والتكاملات؛ لا يفترض أن تثبيت KWin يوفرها تلقائياً.
- لمس متعدد وHDR وإدارة ألوان وقارئ شاشة تحتاج اختبارات عتاد وتكامل خاصة؛ لا تعلن معتمدة دون نتائج.

## حالة البيئة والأعمال المنجزة

تم فحص البيئة دون تعديل إعدادات النظام: Debian forky/sid، Qt 6.11.2، Hyprland 0.56.2 وlabwc 0.20.2. يوجد CMake وdpkg-deb. هذه ليست بيئة اعتماد Debian 13، ووجود البرامج لا يثبت صلاحية جلسة رسومية أو اعتماديات التطوير أو الوصول للعتاد. الدليل السابق للمحادثة لا يتضمن مصادر تنفيذ جاهزة. المجلد الحالي ليس مستودع Git فعالاً، لذا لم تنشأ commit لهذه الوثيقة.

المنجز الآن هو البحث والقرار المعماري وهذه المواصفة فقط. التنفيذ والحزمة والأصول واختبارات الأداء والتوافق لم تنفذ بعد. اعتمد المستخدم تعديل القرار إلى KWin والـshell المخصص؛ الخطوة التالية مراجعة خطة التنفيذ. فحص KWin المحلي لم يجد ملف kwin_wayland تنفيذياً، لذا لا توجد نتيجة تشغيل له حتى الآن.
