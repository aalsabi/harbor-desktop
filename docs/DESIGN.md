# الدليل التقني — Harbor 0.1.0

## البنية

جلسة Wayland مستقلة: مدير الدخول → harbor-session → KWin → harbor-session-client → harbor-shell. يستخدم KWin تركيب النوافذ وإدارتها؛ الشريط والخلفية وdock والمركز والإعدادات مكتوبة محلياً بـQt6/QML. لا يبدأ المشروع plasmashell. استخدام KWayland وKWindowSystem وBreeze لا يعني استخدام واجهة Plasma Shell.

| المكون | التنفيذ والمسؤولية |
|---|---|
| compositor | KWin Wayland؛ حدود النوافذ وتأثير blur وvirtual desktops |
| shell | C++/QML؛ أسطح LayerShellQt منفصلة لكل شاشة وحجز مساحة للشريط وdock |
| إدارة النوافذ | KWayland PlasmaWindowManagement؛ تعداد، تفعيل، تصغير، إغلاق |
| قائمة التطبيقات | GIO desktop entries؛ البحث وإطلاق التطبيق وفق مواصفات سطح المكتب |
| global menu | DBusMenu فقط إذا صدّر التطبيق قائمة؛ لا اختلاق لقوائم غير موجودة |
| tray | StatusNotifierWatcher؛ IconName وActivate وContextMenu |
| الإشعارات | org.freedesktop.Notifications؛ مركز محدود بـ100 عنصر، بدون سجل دائم |
| الإعدادات | QSettings + إشعار تغيّر الملفات لمزامنة تطبيق الإعدادات مع shell |
| الصوت/شبكة/طاقة | عمليات غير متزامنة محددة الوسائط باستخدام wpctl/nmcli/powerprofilesctl |
| المستخدمون | AccountsService على system bus؛ تعديل الاسم الحقيقي مع تفويض Polkit |
| العرض | kscreen-doctor؛ حارس مستقل يعيد الإعداد بعد15 ثانية دون تأكيد |

## عقد الجلسة والعزل

يحفظ KWin إعداداته تحت ~/.config/harbor/session/kwinrc. يعيد عميل الجلسة مسار إعدادات التطبيقات الأصلي؛ لا يستبدل kwinrc الخاص بالمستخدم. الاختبار المتداخل يستخدم مسارات مؤقتة وناقل D-Bus مستقلاً. ينهي المشرف مجموعة عملياته فقط، بما فيها الأبناء عند خروج KWin. لا يشمل ذلك كل تطبيق اختار إنشاء جلسة مستقلة أو خدمة systemd خارج المجموعة؛ يلزم تطوير إدارة جلسة كاملة قبل نشر مؤسسي.

يعلن org.harbor.Shell.desktop بروتوكولات Wayland المطلوبة. يجب تثبيت ملف desktop مع البرنامج ليطابق KWin مسار Exec؛ لا تعطّل فحص صلاحيات البروتوكول لتشغيله. التطبيقات تحصل على صلاحيات المستخدم العادي. لا خدمة مخصصة بصلاحية root ولا كلمات مرور مخزنة. الطلبات المميزة تمر عبر الخدمات الأصلية وPolkit.

## النظام البصري

اسم وهوية Harbor أصلية. خلفية SVG هندسية بحرية وأيقونات SVG محلية؛ لا أصول أو خطوط Apple. الخط Noto Sans من النظام. لوحة داكنة بحرية #101b2c، نص #edf3fa، لون تركيز #64bfb5؛ لوحة فاتحة مقابلة. شريط32px وdock بارتفاع78px؛ زوايا مستديرة وشفافية قابلة للضبط وتقليل للحركة. التمويه يعتمد على دعم KWin وإعداد تأثيره؛ لقطة المعاينة خارج الشاشة لا تثبت جودة GPU.

الثيم Harbor.colors مثبت للاستخدام اليدوي في تطبيقات KDE؛ لا يفرضه هذا الإصدار على كل التطبيقات. زخرفة النوافذ العامة Breeze مفتوحة المصدر مع أزرار يساراً. تطبيق الإعدادات يستخدم إطاراً خاصاً. لا استبدال شامل لأسلوب GTK/Qt ولا محاكاة لمكتبات macOS.

## الحدود الهندسية

نماذج QML تتلقى حالات الخدمات، وتعرض عدم توفرها بدلاً من نجاح وهمي. أوامر الخدمة تستخدم قائمة وسائط دون shell، ومهلاً محدودة. ظهور الخدمات أو الأجهزة الحقيقية واختفاؤها يحتاج مزيداً من اختبارات التكامل. شاشات إعدادات الشبكة المتقدمة والأجهزة الصوتية والاقتران تفتح أدوات خارجية معلنة.

يمكن تشغيل المعاينة دون Wayland، لكنها لا تنشئ جلسة سطح مكتب حقيقية. تطبيق إعدادات منفصل يتشارك ملف تفضيلات shell. العربية مدعومة جزئياً واتجاه الواجهة قابل للتغيير؛ الترجمة الشاملة وتدقيق الوصول بلوحة المفاتيح وقارئ الشاشة متبقيان.

## التطوير والاختبار

CMake يبني البرنامج والمكتبات واختبارات Qt؛ CPack ينشئ حزمة Debian مع اعتماديات محسوبة. scripts/Dockerfile.trixie يحدد بيئة البناء. tests/kwin_integration.py يختبر جلسة افتراضية، tests/benchmark.py يصف قياساً محدوداً قابلاً للتكرار. الأدلة الخام في evidence/. راجع COMPATIBILITY.md قبل أي اعتماد إنتاجي.

تثبّت الحزمة فهرس harbor-applications.menu وتضبط الجلسة XDG_MENU_PREFIX=harbor-؛ يلزم ذلك لفهرسة KService على تثبيت لا يحوي Plasma. يولّد CMake مسار Exec مطلقاً ليتطابق مع الملف التنفيذي في فحص KWin6.3. لا تستبدل الحزمة applications.menu العام.
